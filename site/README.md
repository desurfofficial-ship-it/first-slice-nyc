# First Slice — GitHub Pages Site

This folder contains the project landing page.

## Enable GitHub Pages

1. Go to the repository **Settings → Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Branch: `main`
4. Folder: `/site`
5. Save

After a minute the site will be live at:

**https://desurfofficial-ship-it.github.io/first-slice-nyc/**

(If the folder option does not appear, you can also move `index.html` to `/docs` and select the `/docs` folder instead.)
