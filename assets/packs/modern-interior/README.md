## Formats

- `exports/glb/` — GLB with embedded textures (Godot, three.js, Blender)
- `exports/fbx/` — FBX + texture PNGs next to them (Unity, Unreal)
- `exports/obj/` — OBJ + MTL + texture PNGs
- `previews/` — a preview image of each model

Real-world scale (1 unit = 1 meter), flat shading, one shared palette texture (`palette.png`). Use nearest / point filtering on `palette.png` so the colors stay crisp.
